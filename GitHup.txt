# TRAER CAMBIOS DE GITHUB

## Método normal

```bash
git pull origin Produccion
```

## Forzar y reemplazar todo lo local por GitHub

```bash
git fetch origin
git reset --hard origin/Produccion
```

## Forzar y eliminar archivos sobrantes

```bash
git fetch origin
git reset --hard origin/Produccion
git clean -fd
```

---

# CAMBIAR REPOSITORIO REMOTO

```bash

git remote add origin URL_DEL_NUEVO_REPOSITORIO
git remote -v
```
